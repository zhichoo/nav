# 有意偏差

| 项目 | 原站 | 当前衍生层 | 原因 |
| --- | --- | --- | --- |
| 布局 | 页面内联 CSS、自然换行 flex 卡片 | 原 CSS 逐字提取并先加载 | 先还原布局机制，避免凭观感重写 |
| 基线 | 在线原站 | /baseline/index.html，仅增加 noindex 与归属注释 | 保留可独立对照的原样文档 |
| 数据 | Buzzing 自有多来源翻译内容 | 自有六个公开 RSS / API 实时数据 | 不是把原站内容当作自己实时采集，未翻译时如实保留原文 |
| 品牌 | Buzzing | SIGNAL_ / 信号站 | 自有品牌，不冒充原站 |
| ASCII 皮肤 | 原站暖白、蓝链、圆角阴影 | 暖白纸屏、墨绿链接、等宽字、直角边框、字符分隔 | 用户明确要求的复古 / ASCII 融合，只作用于衍生层 |
| 字体与工具栏 | 原生系统字体、简单链接导航 | ASCII / CRT 使用本机 Menlo 等宽字体与紧凑搜索工具栏，原版布局使用基线字体 | 满足终端视觉，但不占用 Hero 空间 |
| 可访问性 | 截断的卡片仍存在 DOM | 键盘焦点进入截断区域时自动展开；按钮带 aria-expanded / aria-pressed | 避免键盘焦点落到不可见文章 |
| 辅助交互 | 目录、折叠、显示更多 | 保留，并额外提供搜索、布局、风格切换 | 保留已有可用功能，但控制在紧凑工具栏中 |
| 媒体 | 原站外部图片 | 基线继续引用原 URL；自有数据仅展示 RSS/API 提供的图片 | 外部图片未全部离线，不作完整 M0.5 通过声明 |

三种外观均使用自己的实时数据、品牌与辅助功能。只有 `/baseline/index.html` 是原样文档快照，不把「原版布局」选项冒充为原站 DOM 等价实现。文档和 CSS 字节门已通过，完整媒体离线 / 像素门未通过或未执行。
